# OS Rápida Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar criação e finalização atômica de OS Rápida e permitir continuar o rascunho como OS completa sem criar uma quick intermediária.

**Architecture:** Estender `service_orders` com tipo e snapshot explícitos, reutilizar `budget`, desconto e `payment.receipts`, e concentrar a criação quick em uma RPC idempotente. Manter o formulário em componente próprio e passar seu rascunho ao fluxo standard quando o usuário escolher continuar como OS completa.

**Tech Stack:** React 19, TypeScript, Supabase/PostgreSQL, Node test runner, Vite.

**Spec:** `docs/superpowers/specs/2026-09-17-os-rapida-design.md`

## Global Constraints

- Não usar Lovable nem aplicar migrations remotamente.
- Não fazer commit ou push.
- OS quick finalizada nasce `Entregue` e nunca é convertida/reaberta.
- Pagamento zero não exige método; pagamento positivo exige Dinheiro, PIX ou Cartão.
- Preservar integralmente o fluxo standard atual.
