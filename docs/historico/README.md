# Histórico documental

Este diretório preserva a evolução do contexto, dos requisitos e das decisões do PITGARAGE. O objetivo é permitir descobrir como o projeto era, o que mudou, por que mudou, quando mudou e qual passou a ser o estado vigente.

## Regra permanente de preservação

- Não apagar documentação, requisitos, ideias, hipóteses ou decisões anteriores porque ficaram desatualizados.
- Não substituir uma decisão silenciosamente.
- Registrar mudanças pequenas no [`CHANGELOG.md`](../../CHANGELOG.md).
- Para mudanças grandes de requisitos, MVP, arquitetura, modelagem ou escopo, criar uma nova versão conforme [`versoes/README.md`](../versoes/README.md).
- Em uma mudança de decisão, registrar a decisão anterior, a nova decisão, o motivo e o status da anterior: substituída, descartada, adiada ou mantida como futura.
- Manter os documentos atuais acessíveis e seus links funcionando.

Registros históricos devem ser tratados como evidência da evolução. Correções posteriores devem ser registradas em uma nova entrada, sem reescrever silenciosamente o passado.
