# PITGARAGE

Sistema de gestão para uma oficina real de carros e motos. O projeto busca centralizar informações hoje distribuídas entre WhatsApp, papéis, planilhas, cadernos e a memória dos funcionários, tornando o atendimento e o acompanhamento dos serviços mais simples e rastreáveis.

## Estado atual

O projeto está na fase de **Piloto v0.1.1**. Existe uma aplicação local, navegável e baseada em dados fictícios, agora polida para demonstração e validação com a oficina. O piloto não representa aprovação do MVP, da arquitetura ou das decisões técnicas definitivas.

Consulte o índice em [`docs/README.md`](docs/README.md).

## Próximos passos

1. Demonstrar o Piloto v0.1.1 aos responsáveis pela oficina.
2. Registrar feedback sobre fluxo, informações e facilidade de uso.
3. Atualizar requisitos e escopo com base apenas no que for validado.

> O repositório já possui um scaffold gerado pelo Lovable. Sua presença não representa uma decisão técnica aprovada para o produto.
